# Model evaluation

The current desktop runs models and supports explicit review of their proposals;
it does not provide the former Model Evaluation panel or session-report export.
See [running a model](loading-a-model.md).

For an accuracy study, retain independent reference annotations, declare the
observation period and event-matching rules, and perform the evaluation in an
explicit analysis workflow. Accepting model suggestions is not an independent
reference assessment. Comparing `.rime` records examines retained derivations and
result differences; it does not itself calculate model sensitivity or specificity.
