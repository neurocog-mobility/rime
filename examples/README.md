# Software examples

All examples are synthetic and independent of research data.

- [Native workflows](workflows/README.md): annotation, model suggestions, review,
  measurement capture and record overlays, sharing two short videos and one signal.
- [Record exchange](measurement-record/README.md): a small JSON-LD document,
  graph constructors and an independent standard-library recalculation script.

The generated native workflow set is about 2.3 MiB. Workspace paths are relative to their JSON file, so the public examples can move
with the checkout. Keep each workflow folder and its evidence together.
Measurement records remain independently readable without those paths or media.
